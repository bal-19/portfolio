# Developer Portfolio

Portfolio developer 1 halaman, bilingual (ID/EN), gaya bento grid + game-UI, dark theme. Dibangun dengan Vite + React + TypeScript + Tailwind CSS.

Lihat [CLAUDE.md](./CLAUDE.md) untuk konvensi kode dan [docs/design-system.md](./docs/design-system.md) untuk spesifikasi desain.

## Commands

```bash
npm run dev       # jalankan dev server
npm run build     # build production
npm run preview   # preview hasil build
npm run lint       # cek lint
npm run format     # format dengan prettier
```
